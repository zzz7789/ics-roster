# 排班小组件（iOS / iPadOS · Scriptable）

配合 ics-roster 的日历订阅，在 iPhone / iPad 桌面直接看排班，不用打开网页。
支持「今天」「本周」「整月」三种尺寸，底部显示本月各班次数，今天高亮，多人同天重复排班时显示「冲」。

## 文件

| 文件 | 用途 |
| --- | --- |
| `排班小组件.js` | 源码，推荐在 Scriptable 里新建脚本后整段粘贴 |
| `排班小组件.scriptable` | Scriptable 导入包，传到手机上用 Scriptable 打开即可导入 |

## 前置条件

1. 在 ics-roster 排好班；
2. 手机订阅日历（面板里「复制订阅地址」）：
   - 单人：`/api/calendar/person/{id}/{token}.ics`
   - 团队：`/api/calendar/team.ics?token=...`
3. 系统「日历」里能看到这份订阅日历，且已经有事件。

## 配置（通常**不用改代码**）

组件会自己在系统「日历」里找名字带「排班」的订阅日历：

| 场景 | 需要做什么 |
| --- | --- |
| 手机只订阅了自己的**单人**日历（最常见） | 什么都不用做，装上就能用 |
| 订阅了**多份**排班日历 | 长按组件 →「编辑小组件」→ `Parameter` 填自己的名字（如 `张敏`），也可填完整日历名（如 `张敏 排班`） |
| 用**团队**日历（事件标题是「张敏 早班」） | 同上，`Parameter` 必须填自己的名字，否则组件提示「团队日历需要指定名字」 |

脚本开头的两行是兜底配置，一般留空：

```js
const CALENDAR_TITLE = "" // 固定日历名，留空 = 自动查找含「排班」的日历
const PERSON_NAME = ""    // 团队日历里自己的名字，留空 = 用组件 Parameter
```

优先级：组件 `Parameter` > 脚本内 `PERSON_NAME` / `CALENDAR_TITLE` > 自动查找。

匹配规则：
- 单人日历的事件标题就是「早班」「晚班」「休息」，不做姓名过滤；
- 团队日历才会按名字过滤——名字取自 `Parameter`，没填就提示需要指定；
- 参数里写的名字在日历中匹配不到时，组件提示「未找到排班日历」。

## 与 ics-roster 的格式对应

| 班次 | 事件标题 | 日历形态 | 组件显示 |
| --- | --- | --- | --- |
| 早班 | `早班` / `张敏 早班` | 定时事件 09:00–17:00 | 绿色「早」+ 时间 |
| 晚班 | `晚班` / `张敏 晚班` | 定时事件 17:00–次日 00:00 | 橙色「晚」+ 次日 00:00 |
| 休息 | `休息` / `张敏 休息` | 全天事件 | 青色「休」+ 全天休息 |

组件里的时间不再写死，直接从事件起止时间读取；标题按关键字包含匹配（`早班` / `晚班` / `休息`），
所以团队订阅带姓名前缀也能识别。

## 底部统计

图例行显示**当月各班次数**，颜色点与日历里一致：

| 尺寸 | 统计月份 | 显示样式 |
| --- | --- | --- |
| 小号 | 当前月 | `● 早 12　● 晚 11　● 休 7` |
| 中号（本周） | 当前月 | `● 早班 12　● 晚班 11　● 休息 7` |
| 大号（整月） | 组件里显示的月份（可能已切到下月） | `● 早班 12　● 晚班 11　● 休息 7` |

统计按「当天有该班次的天数」算，同一天出现多个班次时按冲突处理、不计入统计。

## 导入步骤

**方式 A（推荐）**
1. 把 `排班小组件.scriptable` 传到 iPhone（AirDrop / 文件 App / iCloud）；
2. 点击文件 → 用 Scriptable 打开 → 自动导入到脚本列表。

**方式 B**
1. 打开 Scriptable → `+` 新建脚本；
2. 粘贴 `排班小组件.js` 全部内容 → 重命名保存。

然后：长按桌面 → 左上角 `+` → Scriptable → 选尺寸 → 添加后长按组件「编辑小组件」→ 选择脚本。

## 刷新

组件会在每 30 分钟或零点自动刷新一次。
日历客户端拉取订阅本身有延迟（Apple 日历通常几小时一轮），发现数据没更新时可在「日历」App 里下拉刷新订阅。

## 说明

- 组件只读系统日历，不直接访问 ics-roster 接口，所以订阅地址轮换后只需在日历里重新订阅。
- 同一人同一天出现两条及以上班次时按「排班冲突」显示，提醒去面板修正。
